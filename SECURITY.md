
# Security Policy

ClinicFlow AI is a portfolio project using synthetic data. Do not submit real patient information, credentials, access tokens, API keys, or confidential clinic information to this repository.

## Security design

The application follows least privilege, deny-by-default tool access, structured input validation, immutable audit events, secret externalisation, and explicit human approval for booking execution.

## Reporting

For this portfolio repository, open a private contact channel before publishing details of a security vulnerability. Do not include sensitive data in public GitHub issues.

## AI-specific reporting

Report prompt injection, unsafe tool-use, schema bypasses, unintended data access, excessive authority, or failure to respect human approval boundaries as security issues.
