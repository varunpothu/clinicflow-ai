# Visual Design System

The repository illustrations use a consistent semantic colour language:

- 🔵 **Blue** — user requests, APIs and transactional execution
- 🟣 **Purple** — AI interpretation and intelligent assistance
- 🟢 **Teal/green** — deterministic controls, validation and successful completion
- 🟠 **Orange** — human approval and operational decisions
- 🔴 **Red** — conflicts, failures and recovery paths
- ⚫ **Dark** — safety boundaries and key engineering principles

The colour is intentionally semantic rather than decorative. A reader should be able to understand the control boundary before reading every label.
