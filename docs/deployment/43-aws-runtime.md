# AWS Runtime

## Network

Public subnets contain the internet-facing ALB and NAT gateway. Private subnets contain ECS tasks and RDS PostgreSQL.

## Security

The ALB can reach ECS on port 8000. ECS can reach RDS on port 5432. RDS does not accept public traffic.

## Secrets

The PostgreSQL password is generated by Terraform and stored in Secrets Manager. Production deployments should separate secret generation from long-lived Terraform state where the security model requires it.

## AI

The ECS task role receives Bedrock inference permissions. In production, replace the wildcard Bedrock resource with the minimum supported model/resource scope for the chosen deployment.

## Cost trade-off

NAT gateways are operationally simple and support broad outbound access, but they add cost. A VPC-endpoint-based design can reduce NAT dependency and limit traffic to approved AWS services. The default design favours straightforward production behaviour for an FDE demonstration.
